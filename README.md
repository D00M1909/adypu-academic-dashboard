# ADYPU Academic Dashboard

Live academic view for Ajeenkya D Y Patil University: School → Year → Division →
student attendance.

Separate from the `adypuacademicreport` monthly report site, though the two share
branding.

**[SPEC.md](SPEC.md) is the full project spec** — design decisions, brand tokens,
data model, tech stack, and the open questions blocking implementation. Read it
before writing code.

Visual mockups: open `design/adypu-drilldown-design-options.html` in a browser
(kept locally, not tracked).
